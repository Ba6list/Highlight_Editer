# 検証結果

実施日：2026-10-14（日本時間）

## 成功した確認

- TypeScriptの型検査、Viteの本番ビルド
- Workers実行環境、ローカルD1・R2を使用した自動テスト40件
- 専用フォルダでのD1マイグレーション37文の適用
- ローカルHTTPでログイン、初期状態、再生リスト作成・保存・競合・削除、検索、PIN付き設定、ログアウト
- Wranglerのデプロイdry-run：Workerと静的ファイルのパッケージ生成成功。実際の公開はしていません
- 公開URL・D1 IDが未設定の場合のデプロイ事前チェックが安全に停止すること
- npm audit：開発依存も含め、既知の脆弱性0件

## 自動テストの対象

認証Cookie（HttpOnly / Secure / SameSite=Lax / 12時間）、OriginとCSRF、PIN、試行制限、セッション失効、暗号化の改ざん検知、OBSトークンの権限・失効。

0.1秒範囲保存、範囲外拒否、更新競合、公開スナップショットの固定、下書き・公開・再生中素材の保護、ロック、動画のRange応答。

Twitchへの60秒要求、公式ダウンロードAPI経由のR2保存、実際の動画長の反映、同じ要求IDの重複防止、作成応答不明時の警告。

Driveの容量不一致・通信失敗時のR2保持、成功確認後の削除、転送済み位置から再開、R2削除後・DB完了前の回復、24時間復元、Cronの開始・定期清掃。

6種の保存期間、作成日時からの期限計算、既存適用、全件検索・検索記号、PNG未登録の公開、内部PNG検証用データの登録・使用中削除拒否、OAuthスコープと不正state拒否。

Twitch・Googleへの通信は模擬応答です。テスト動画データは容量・転送処理の検証用バイト列であり、実際のMP4再生を検証したものではありません。PNGの内部テスト用データは本番アプリへ登録していません。フレームのデザインは作成していません。

## 未検証

- 外部アカウントの初回OAuth、実際のTwitchクリップ動画、Google Driveへの実転送
- Cloudflare本番のCPU 10ms制限、Cron転送速度、実際の請求額
- OBS実機での音声、自動再生、先読み、60fps、切り替えの滑らかさ
- 実ブラウザでの見た目と操作、スマートフォン・タブレットでの操作
- GitHub Actionsの実リポジトリでの実行と本番デプロイ

画面操作による検証は、ブラウザツールがローカルURLへの操作をURLポリシーで拒否したため実施できていません。制限を回避する別のブラウザ操作は行っていません。

本番確認は [受け入れ確認](ACCEPTANCE.md) に記載しています。上記の自動テスト成功だけで「大会で実運用確認済み」とは扱いません。

## 未実装・対象外

MP4結合書き出し（第2段階）、Chrome拡張（将来）、配信PCへの完全なオフラインキャッシュ、OBS WebSocket直接制御、一括大量削除、シーズン別Driveサブフォルダ。

## 残る制限

素材は1件100MB以内、PNGは5MB以内・4096px以内、1再生リスト100項目以内。管理一覧は48件ずつ全件検索できます。概要には最近の1000件と未アーカイブ素材を表示し、集計数と容量はDB全体から算出します。

1分Cronで1段階・最大4MB転送です。大量の期限切れ素材では順番待ちになります。下書きで使っている素材も保留するため、使い終わった再生リストを整理してください。

動画容量の取り込み上限は課金全体の停止機能ではありません。他のR2バケット、孤立したファイル、操作回数による課金はCloudflare側で確認してください。
