# 大会スタッフ向け操作マニュアル

## ログイン

共有されたアプリURLを開き、任意の表示名と共通パスワードを入力します。表示名は操作ログに残ります。12時間で再ログインが必要です。スタッフ個別のアカウント登録はありません。

## 配信前の準備（管理者・配信担当）

1. システム設定でTwitchとDriveが接続済みか確認します。
2. ストレージ画面で容量、エラー、保存期間を確認します。初期保存期間は1週間です。
3. システム設定で管理者PINを使ってOBS専用URLを発行します。
4. OBSで「HIGHLIGHT」シーンを作ります。
5. ソースの「＋」→「ブラウザ」を選び、名前を「NOBORI Highlight」にします。
6. URLに発行した専用URLを貼り、幅1920・高さ1080にします。
7. 「表示されていないときにソースをシャットダウン」「シーンがアクティブになったときにブラウザの表示を更新」をオンにします。上映はシーンに切り替わった時に先頭から開始する運用です。
8. ブラウザソースの音声が出るか、OBSの音声ミキサーで確認します。必要なら「OBSで音声を制御する」をオンにし、モニターと配信出力の設定を確認します。
9. 短いテスト用再生リストを公開し、画面・音声・トリミング・順番・終了後黒画面を確認します。

通常のChrome等では、音声の自動再生が制限される場合があります。その場合だけ「音声付きで再生を開始」を押します。OBSでこのボタンが出る場合、本番に入る前にOBSのブラウザソース設定と実機で確認してください。

## クリップ担当

1. 公式Twitch配信を視聴します。
2. アプリの「クリップを保存」を開きます。
3. 必要なプレーが出たら「SAVE CLIP」を押します。
4. 受付中の短時間は連打できません。受付後は次のプレーを保存できます。
5. 「最近の保存状況」で保存完了を確認します。生成・取得・保存を順番に表示します。
6. タイトルは任意です。空欄では日時付きの名前になります。

最大60秒を要求しますが、素材の長さや切り取る位置はTwitchの状況に左右されます。視聴遅延があるため、必ず素材を見て必要な場面を選びます。通信切断で要求結果が不明なときは、同じ画面でボタンを再度押すと同じ要求IDで再試行します。同じタブの再読み込み後も未確認の要求IDを保持します。別のタブでの再要求前には、一覧を確認してください。

## Twitch画面で保存する（Chrome拡張）

対応版を公開後、[NOBORI Clipの導入手順](../extension/README.md)で拡張をChromeへ読み込みます。アプリのシステム設定から接続コードを発行し、拡張アイコンの入力欄へ貼り付けます。以後はnobori_officialの配信ページ右下にSAVE CLIPと最近の保存状態が表示されます。タイトルと最大30秒/60秒を選んで保存できます。編集画面はパネルのリンクから開きます。

コードは5分・一度限りで、拡張の接続は元のログイン期限、ログアウト、Chrome終了で切れます。再接続時はコードを発行し直してください。パスワード・PIN・サービスのSecretは拡張へ入力しません。

## 編集担当

1. 「再生リストを作成」し、編集画面を開きます。またはクリップ詳細の「編集する」から開始します。
2. 「クリップを追加」で使用する素材を選びます。
3. 再生順の行を選ぶとプレビューに表示されます。
4. 開始・終了を0.1秒単位の時間入力、またはスライダーで調整します。
5. ドラッグで並び替えます。スマートフォンでは上・下ボタンを使います。
6. 複製ボタンで同じ素材を別の範囲として追加できます。ゴミ箱ボタンは再生リストから外すだけで、元動画は消しません。
7. PNGがある場合、再生範囲欄のフレーム選択で設定します。「フレームなし」で非表示にします。
8. 「全体をプレビュー」で順番と範囲を確認します。
9. 編集内容は変更後に自動保存します。「保存済み」になるまで確認します。
10. 完成したら「公開する」を押します。保存だけではOBSへ変更が出ません。

他のスタッフの変更と競合した場合、自分の編集内容を端末に保持して上書きを止めます。スタッフ間で調整してから「自分の変更を破棄して最新版を読む」を選びます。自分の変更が必要な場合は画面を残して、順番に編集し直してください。未送信データの復元ボタンは通信切断からの回復用です。

## 配信担当

1. 編集担当から公開完了の連絡を受けます。
2. アプリの概要で公開中の再生リストを確認します。
3. インターバルでOBSをHIGHLIGHTシーンに切り替えます。
4. 専用URLを毎回変える必要はありません。
5. 全素材の終了後は黒画面で停止します。設定に応じて待機表示または繰り返しも選べます。
6. 次のシーンへ戻します。

上映中に新しい内容が公開されても、その上映途中で置き換えません。次回のシーン切り替えによる再読み込み時に最新版を上映します。プレーヤーの接続確認は最大約15〜20秒遅れます。

## アーカイブ

- 初期保存期間は1週間。管理者は1日・3日・1週間・2週間・3週間・30日から変更できます。
- 「既存クリップにも適用」をオンにすると個別設定を含めて期限を作成日時から再計算します。すでに期限超過の素材は転送対象になります。
- クリップ「詳細・変更」で個別の保存期限を変える場合もPINで保護します。
- 即時転送はクリップ詳細の「手動アーカイブ」を使います。
- **下書きの再生リスト、公開中、OBS再生中の動画は転送しません。** 使用を終えたら公開を停止し、保存した再生リストから素材を外すか再生リストを削除します。元動画の削除ではありません。
- 転送は4MBずつ進むため、数分〜時間がかかります。ストレージ画面で進捗・エラーを確認できます。「期限超過・転送待ち一覧」から対象素材を一覧表示できます。
- Drive保存が確認できるまでR2の動画を削除しません。
- 過去素材は「アーカイブ」でタイトル・タグ検索します。「復元する」でR2へ一時コピーし、編集に再利用できます。Driveの元ファイルは残ります。復元期限は24時間です。再生リストで使用中なら保留します。

## PNGフレーム

1. 「PNGフレーム」で制作済みの透過PNGを選択します。
2. 管理者PINを入力してアップロードします。5MB以内、推奨1920×1080です。
3. 編集画面で各クリップにフレームを指定します。
4. プレビューを確認して公開します。

既存PNGは同じIDで上書きしません。差し替えは新しくアップロードし、再生リストで選び直して公開します。再デプロイや動画の変換は不要です。登録がない場合も動画だけで編集・上映できます。

## 削除

クリップ詳細の削除は確認画面を出します。公開中・処理中・再生リストで使用中なら拒否します。Driveの保存済みファイルは削除しません。再生リストの削除は動画を削除しません。大量一括削除は初版では用意していません。
