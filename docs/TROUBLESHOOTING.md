# 困ったとき

| 症状                            | 確認する場所・対処                                                                                                                                |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| ログインできない                | 共通パスワードを確認。15分の試行制限なら待つ。「初期設定が未完了」はAUTH_KEY等のSecretを確認                                                      |
| アクセス元が一致しない          | CloudflareのAPP_ORIGINとブラウザのURLが同じか確認。http/https・ドメイン・ポートも一致させる                                                       |
| 画面を再読み込みしてと言われる  | セッション期限・CSRF情報が変化した可能性。再ログイン                                                                                              |
| Twitch OAuthが失敗              | ConsoleのRedirect URL、nobori_officialアカウント、Client ID/Secret、認可権限を確認                                                                |
| オフラインと出る                | Twitchを実際に配信中にしてから保存する。別アカウントを使用しない                                                                                  |
| Twitchの生成が終わらない        | 一覧のエラーを確認し再試行。公式Twitch側のクリップ一覧も確認。作成応答の通信断では作成済みの可能性があるため自動で再作成しない                    |
| 動画を取得できない              | channel:manage:clipsで再接続。横向き動画の準備待ち・制限・配信終了付近の短い素材に注意                                                            |
| 容量上限で保存できない          | 保存期間・再生リストから不要素材を外す・アーカイブを確認。公開・上映中素材は転送されない                                                          |
| Drive接続が7日で切れる          | Google OAuthアプリがTestingか確認。Productionへ移行後に再接続                                                                                     |
| Drive転送に失敗                 | 接続認可・Drive空き容量・同じGoogleアカウントか確認。クリップ詳細の再試行で再開。元動画は削除しない                                               |
| 自動転送が進まない              | 保存期間が作成日時から計算されているか確認。下書き・公開・OBSで使う素材を外す。CloudflareのCron TriggersとMetricsを確認                           |
| Worker exceeded resource limits | 無料CPU 10msを超えた可能性。CloudflareのMetricsを確認。本番で継続発生する場合は上映を止め、無料代替方式を相談。有料プランへの変更を自動で行わない |
| 更新が競合した                  | 自分の編集は端末に残る。ほかのスタッフと調整し、最新版を読んでから一人ずつ編集する                                                                |
| OBSが黒い                       | 公開済み再生リスト・有効な再生URL・R2素材の存在を確認。終了後の黒画面は正常。スタッフ画面の通信状態も確認                                         |
| OBSの音が出ない                 | ブラウザソースの音声制御、ミキサー、モニター、出力先を確認。通常ブラウザでは手動の再生開始が必要な場合あり                                        |
| OBSが先頭から再生しない         | シーンアクティブ時のブラウザ更新・非表示時シャットダウンをオン。シーンを一度切り替える                                                            |
| PNGが出ない                     | 編集画面のフレーム指定と再公開を確認。登録だけでは公開映像を変えない                                                                              |
| Actionsが失敗                   | checkのテスト結果、Cloudflare API Tokenの権限、アカウントID、D1 ID、R2名を確認                                                                    |

## 安全な復旧

転送失敗時にR2の動画を手動で削除しないでください。Driveの同名動画を見つけても、アプリの転送履歴で確認するまでは成功扱いにしません。

秘密情報の暗号鍵TOKEN_ENCRYPTION_KEYを変更すると、保存済みのOAuth情報・転送セッションを読めなくなります。鍵の変更は通常の設定操作ではありません。バックアップと再認可を計画してください。AUTH_KEYを変更するとパスワードのHMAC・PIN・OBSトークンも再設定が必要です。

D1のマイグレーションはGitHub Actionsで適用します。適用済みファイルは編集せず、新しい番号のマイグレーションを追加します。将来、破壊的な変更をする場合はD1の復旧ポイントと退避を先に確認します。

通信障害でOBSの全クリップが先読みできていないと途中停止する場合があります。ブラウザソースのみで無制限のオフライン上映はできません。本番前のテストで配信PC・ネットワークの状態を必ず確認します。
