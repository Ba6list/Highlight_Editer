# NOBORI Clip（Chrome拡張）

Twitchで公式配信を見ながら、同じ画面からクリップを保存します。編集・管理・OBSの機能はアプリで行います。Chrome Web Storeには未公開のスタッフ用初版です。

## 初回インストール

1. アプリの「システム設定」→「Chrome拡張をダウンロード（ZIP）」で取得したZIPを展開します。`nobori-clip`フォルダ内に`manifest.json`があることを確認します。
2. Chromeで`chrome://extensions`を開き、右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」で`nobori-clip`フォルダを選びます。ソースから入れる場合はこのプロジェクトの`extension`フォルダです。
4. Chromeの拡張メニューでNOBORI Clipをピン留めします。

## スタッフの接続

この版に対応したアプリの本番公開とD1マイグレーションを先に完了してください。拡張を入れただけでは旧サーバーへ接続できません。

1. https://nobori-highlight-studio.nbrhg.workers.dev/#settings へ共通パスワードでログインします。
2. 「Twitch画面からクリップを保存」→「接続コードを発行」→コピーします。
3. ChromeのNOBORI Clipアイコンを押し、コードを貼って「このChromeを接続する」を押します。
4. https://www.twitch.tv/nobori_official を開くか、すでに開いている場合は再読み込みします。
5. 右下のパネルでタイトル（任意）・最大30秒/60秒を選び、配信中にSAVE CLIPを押します。
6. 保存状況を確認します。未確認と出たら同じ要求の再試行ボタンを使います。別タブから重ねて保存する前に一覧を確認してください。
7. 細かい編集はパネルの「編集画面を開く」から行います。小さくしたいときは「−」を押します。

普通の視聴画面・シアターモードを推奨します。フルスクリーンはTwitch側の表示方式によりパネルが出ない場合があります。

## 接続期限・安全性

- コードは5分間・一度限り。他の人へ渡したり、公開チャンネルへ貼ったりしないでください。
- ログインから最大12時間、アプリのログアウト、パスワード/PIN変更、アプリからの拡張解除で接続は失効します。Chrome終了でも拡張側の認証情報は消えます。再起動後はコードを発行し直します。
- 拡張にパスワード・管理者PIN・Twitch/GoogleのSecretを入力しません。
- 認証トークンは拡張のメモリ用保存領域に置き、Twitchのページへは渡しません。PCの利用者自身から情報を隠す仕組みではありません。
- Twitch内の移動を検知するためTwitchページ上でスクリプトを起動しますが、操作パネルと保存機能はnobori_officialのチャンネルページだけで動きます。配信映像・チャット・TwitchのCookieは読み取りません。
- 最近のクリップ5件のタイトル・保存状態・エラーを表示できます。素材の編集・削除・再生URL取得・管理設定変更はできません。
- アプリのAPIだけへ通信します。常時開いたままにする必要はありません。非表示タブと折りたたみ時には定期確認を止めます。

## 更新・トラブル

- ソース更新後は拡張管理画面で更新し、Twitchタブも再読み込みします。
- 接続エラーは拡張アイコンを開いて確認します。拡張だけの解除はアイコンの「接続を解除」、紛失等でまとめて解除する場合はアプリの同じログインから「このログインの拡張接続を解除」を使います。
- 保存受付後にTwitch側で生成できない場合もあります。最大秒数や視聴中の場面が確実に入ることは保証されないため、編集画面で動画を確認してください。
- インストール実機、Twitch上のパネル表示、実配信クリップ取得、OBS上映は別途受け入れテストが必要です。
